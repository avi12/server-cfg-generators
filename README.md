# server.cfg Generators

Whip up a `server.cfg` for your game server, right in the browser:

- [Team Fortress 2](https://avi12.github.io/server-cfg-generators/tf2)
- [Counter-Strike 2](https://avi12.github.io/server-cfg-generators/cs2)
- [Garry's Mod](https://avi12.github.io/server-cfg-generators/gmod)

## Development

```sh
pnpm install
pnpm dev
```

`pnpm build` type-checks and bundles into `dist/`. Every push to `main` deploys to GitHub Pages.

Made by [Avi](https://avi12.com).
